task 1

Объявите переменную типа `number` и присвойте ей любое числовое значение.
Объявите переменную типа `boolean` и присвойте ей значение `true` или `false`.

Создайте переменные для типов данных `null` и `undefined`

Объявите переменную и присвойте ей значение `null`.
Объявите переменную типа `undefined`.

Создайте переменную типа `any` и присвойте ей различные значения

Начните со строки, затем измените значение на число.

Напишите функции, которые принимают параметры с этими типами данных и возвращают строки, объясняющие, что это за тип данных.

task 2 ==============================================================

Напишите функцию `division`, которая принимает два числа в качестве параметров и возвращает их частное. Используйте строгую типизацию.

Создайте интерфейс `Car`, который описывает автомобиль с полями `make`, `model`, `year`, и `isElectric`.
Напишите функцию, которая принимает объект типа `Car` и выводит информацию об автомобиле.

Создайте массив чисел и напишите функцию `calculateSum`, которая принимает массив чисел и возвращает их сумму. Добавьте строгую типизацию.

Создайте интерфейс `Task`, который описывает задачу с полями `title`, `description` и `isCompleted`.

Напишите функцию, которая принимает массив задач и выводит только невыполненные задачи.

Напишите функцию `greet`, которая принимает имя (строка) и возраст (число). 

Выведите сообщение с приветствием и возрастом.

Напишите функцию `convertToUpperCase`, которая принимает строку и возвращает её в верхнем регистре. Используйте строгую типизацию.

task 3 ===========================================================================

1. Создайте массив чисел `scores`, представляющий результаты тестов студентов. 
Напишите функцию `averageScore`, которая принимает этот массив и возвращает средний балл.

2. Создайте массив объектов `products`, где каждый объект описывает товар и содержит следующие свойства: `name` (строка), `price` (число), и `inStock` (булево значение). 
Напишите функцию `listAvailableProducts`, которая принимает этот массив и выводит названия товаров, которые есть в наличии.

3. Создайте переменную `data` типа `unknown`, которая может принимать значения разных типов.

Напишите функцию `processData`, которая принимает эту переменную и проверяет ее тип.

Если это строка, функция должна вернуть её длину.

Если это число, функция должна вернуть его квадрат. В любом другом случае функция должна вернуть `null`.
