Откройте ваш редактор кода и создайте новую директорию для проекта, например, `routerWebServer`.

Внутри директории проекта создайте файл с именем `server.js`.

В начале файла `server.js` импортируйте встроенный модуль `http`.

Используйте метод `http.createServer`, чтобы создать сервер. Определите функцию обратного вызова, которая принимает объекты `request` и `response`.

Реализуйте маршруты в функции обратного вызова:
`/` - главная страница, отвечает текстом "Welcome to the Home Page!".
`/about` - страница "О нас", отвечает текстом "About Us".

Любой другой маршрут - отвечает текстом "404 Not Found".

6.        Используйте метод `listen` объекта сервера, чтобы запустить его на определенном порту (например, 3000).

7.        В терминале перейдите в директорию проекта и выполните команду `node server.js` для запуска сервера.

8.        Откройте браузер и перейдите по адресу `http://localhost:3000`, `http://localhost:3000/about`, и любому другому

Task3

Требования:
Импортируйте встроенный модуль http. 
Создайте сервер, который будет работать на порту 3000. 
При обращении к разным маршрутам сервер должен возвращать разные ответы:
/ — Добро пожаловать на главную страницу! 
/about — Это страница "О нас". 
/contacts — Наши контакты: example@mail.com 
Любой другой маршрут — статус 404 и текст Страница не найдена. 
После запуска сервера выведите в консоль сообщение:Сервер запущен: http://localhost:3000
Дополнительно 
Для каждого запроса выводите в консоль запрошенный URL и HTTP-метод. 
Например:

GET /
GET /about
GET /contacts
GET /test
