Задача 1 — «Цитатник» 
Сервер хранит массив строк-цитат.

GET /quotes — вернуть все цитаты
GET /quotes/random — вернуть одну случайную
POST /quotes — добавить цитату из тела запроса { "text": "..." }. Если text пустой или отсутствует — вернуть 400 с сообщением об ошибке.

Задача 2 — «Список задач» 
Массив объектов { id, title, done }.

GET /todos — все задачи
GET /todos/:id — одна задача по id, если нет — 404
POST /todos — создать задачу (id генерировать на сервере, done: false по умолчанию)

Задача 3 — «Гостевая книга с валидацией» 
Массив сообщений { id, name, message, createdAt }.

POST /messages — принять { name, message }. Валидация: name от 2 символов, message от 5 до 200. При ошибке — 400 и объект вида { errors: [...] } со списком всех ошибок сразу, а не только первой.
GET /messages — все сообщения, отсортированные от новых к старым
GET /messages/count — вернуть { count: N }

Задача 4 — «Регистрация на мероприятие» 
Объект мероприятия: { title: "JS Meetup", capacity: 5, participants: [] }.

GET /event — информация о мероприятии + сколько мест осталось (вычислять, не хранить)
POST /event/register — принять { email }. Проверки: email содержит @, участник ещё не зарегистрирован (иначе 409), есть свободные места (иначе 409 с текстом «мест нет»)
GET /event/participants — список участников, но email замаскировать: i***@mail.com
