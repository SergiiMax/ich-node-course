Задание: Фронтенд «Кинотека» на React + Vite
Цель: научиться делать SPA на React, которое общается с готовым REST API — получать данные (GET), отправлять данные (POST), обрабатывать состояния загрузки/ошибки и валидировать формы на клиенте.
Стек: React, Vite, axios. Бэкенд уже готов (папка 16-july) и запускается отдельно, фронт с ним не связан кодом — только HTTP-запросами.

Подготовка

Убедиться, что бэкенд запущен (npm run dev в папке 16-july) и известен его порт из .env.
В папке front создать файл .env с переменной VITE_API_URL — базовый адрес API, например http://localhost:3000/api.
Добавить .env в .gitignore, а рядом положить .env.example.
Все запросы к серверу делать через import.meta.env.VITE_API_URL, а не через захардкоженный адрес.

Страница со списком фильмов

При загрузке страницы делать GET /api/movies и выводить карточки: title, year, genre, средний рейтинг (посчитать по ratings).
Пока идёт запрос — показать индикатор загрузки; если запрос упал — сообщение об ошибке вместо списка.
Клик по карточке открывает страницу конкретного фильма.

Страница фильма

Получить данные фильма через GET /api/movies/:id.
Показать title, year, genre, средний рейтинг, количество оценок и список отзывов (author, text, createdAt).
Если сервер вернул 404 — показать «Фильм не найден» вместо страницы с ошибкой в консоли.

Добавление фильма — форма (основная часть)

Форма с полями title, year, genre.
Валидация на клиенте перед отправкой: title — непустая строка, year — число от 1895 до текущего года, genre — непустая строка. Ошибки показывать под соответствующим полем, запрос при невалидных данных не отправлять.
Отправка POST /api/movies. Если сервер вернул 400 — вывести текст ошибки из ответа.
Успех (201) — добавить фильм в список на странице без перезагрузки (обновить состояние, а не рефетчить весь список).

Оценка фильма

На странице фильма — поле ввода или слайдер для оценки и кнопка «Оценить».
Клиентская валидация: value — число от 1 до 10, иначе кнопка отправки заблокирована или показывается ошибка.
Отправка POST /api/movies/:id/ratings. Успех (201) — обновить на странице средний рейтинг и количество оценок значениями из ответа сервера (не пересчитывать самому).

Отзывы

Форма с полями author и text.
Клиентская валидация: оба поля обязательны, text — минимум 10 символов.
Отправка POST /api/movies/:id/reviews. Успех (201) — добавить отзыв в список на странице, используя объект из ответа сервера (там есть createdAt).
Ошибка (400) — показать текст ошибки под формой, отзыв не добавлять.
