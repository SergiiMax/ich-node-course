Recipes API — схема базы данных

Спецификация для реализации на MySQL 8 + Sequelize. Типы, обязательность, значения по умолчанию, внешние ключи и индексы выгружены из работающей базы — переносить в миграции можно один в один.

PKпервичный ключ FKвнешний ключ UKуникальный IDXиндекс NOT NULL NULLдопускает пустое значение

Связи

Как читать: || — ровно один, o{ — ноль или много, |o — ноль или один. Например CUISINES |o--o{ RECIPES: у рецепта кухня может отсутствовать (cuisine_id nullable), а у кухни может быть сколько угодно рецептов.

Проверки на уровне приложения

То, что база не сторожит, но обязано быть в моделях и роутах.

ПравилоГде реализуется
rating в диапазоне 1…5валидация min/max модели Review — в БД TINYINT UNSIGNED допускает 0…255
корректный email, username 3…50валидации модели User
пароль от 6 символоввалидация виртуального поля password
slug уникален с учётом мягко удалённыхпоиск с paranoid: false перед вставкой
rating_avg и review_count согласованы с reviewsпересчёт в той же транзакции
автор рецепта и отзываберётся из JWT, поле userId из тела запроса игнорируется
