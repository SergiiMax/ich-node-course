1. Установите необходимые зависимости
○В выбранной вами директории инициализируйте новый проект: npm init -y.
○В добавьте “type”:”module” файл `package.json`, чтобы использовать import.
○Установите все необходимые зависимости, для этого выполните команду в терминале:
npm install express bcrypt
2. Настройте базовое Express-приложение
Создайте файл `index.js` и настройте в нем базовое приложение Express. Не забудьте подключить middleware для работы с JSON, чтобы ваше приложение могло обрабатывать данные, которые приходят в теле запроса.
3. Создайте массив для хранения пользователей
Для простоты создайте массив `users`, который будет временно хранить зарегистрированных пользователей. В реальном приложении это будет база данных.
4. Реализуйте маршрут для регистрации
Создайте маршрут POST `/register`, который будет обрабатывать запросы на регистрацию новых пользователей:
○Извлекайте `username` и `password` из тела запроса.
○Хэшируйте пароль с помощью `bcrypt`.
○Сохраняйте пользователя с хэшированным паролем в массиве `users`.
○Возвращайте клиенту сообщение о успешной регистрации.
5. Тестирование.
Запустите ваше приложение, проверьте, что все работает так, как должно.

1.Реализуйте маршрут для логина
Создайте маршрут POST `/login`, который будет обрабатывать запросы на вход:
○Извлекайте `username` и `password` из тела запроса.
○Найдите пользователя в массиве `users` по `username`.
○Если пользователь найден, сравните введенный пароль с хэшированным паролем из массива с помощью `bcrypt.compare()`.
○Если пароли совпадают, отправьте сообщение о успешном входе. Если нет, верните сообщение об ошибке.
1.Тестирование
○Запустите ваше Express-приложение.
○Проверьте маршрут регистрации, отправляя POST-запросы с логином и паролем.
○Проверьте маршрут логина, отправляя POST-запросы с правильными и неправильными паролями, чтобы убедиться, что проверка пароля работает корректно.
