Задание: обновление пользователя (PUT-запрос)
У вас есть Express-сервер, подключённый к базе данных через Sequelize, и модель User с полями id, name и email. Реализуйте маршрут для обновления данных пользователя.
Маршрут: PUT /user/:id
Тело запроса (JSON): можно передать одно или оба поля:
json
{
  "name": "Alice Smith",
  "email": "alice.smith@example.com"
}
Требования:
Проверьте параметр id из URL: он должен быть целым положительным числом. Если id некорректный (например, abc, -5, 1.5), верните 400 Bad Request с сообщением «Некорректный id».
Если в теле запроса не передано ни name, ни email, верните 400 Bad Request с сообщением «Передайте хотя бы одно поле: name или email».
Найдите пользователя по первичному ключу. Если пользователь не найден, верните 404 Not Found с сообщением «Пользователь не найден».
Если передан новый email и он отличается от текущего, проверьте, не занят ли он другим пользователем. Если занят, верните 409 Conflict с сообщением «Пользователь с таким email уже существует».
Обновите только переданные поля. Непереданные поля должны остаться без изменений.
При успешном обновлении верните 200 OK и обновлённый объект пользователя.
Все ошибки передавайте в глобальный обработчик через next(). Для ошибок с HTTP-статусом используйте класс HttpError(status, message).
Оберните тело обработчика в try/catch, чтобы непредвиденные ошибки (например, ошибки базы данных) тоже попадали в next(error).
Примеры ответов:
Ситуация Статус Ответ
Успешное обновление 200 { "id": 1, "name": "Alice Smith", "email": "alice.smith@example.com" }
id = abc 400 { "error": "Некорректный id" }
Пустое тело {} 400 { "error": "Передайте хотя бы одно поле: name или email" }

email уже занят другим пользователем 409 { "error": "Пользователь с таким email уже существует" }

Проверка в Postman: создайте запросы для каждой ситуации из таблицы и убедитесь, что сервер возвращает правильный статус-код и сообщение.
Подсказки:
User.findByPk(id) ищет запись по первичному ключу.
User.findOne({ where: { email } }) ищет запись по значению поля.
user.update({ name, email }) сохраняет изменения. Поля со значением undefined Sequelize пропускает.
