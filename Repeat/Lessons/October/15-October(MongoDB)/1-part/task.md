1.Создание проекта и установка необходимых пакетов
○Откройте терминал или командную строку и создайте новую папку, в которой будет располагаться ваш проект. Например:
○Выполните команду `npm init -y`, чтобы инициализировать проект.
○Для работы с Express, MongoDB и переменными окружения вам потребуются следующие пакеты.
●`express` – фреймворк для создания веб-сервера.
●`mongodb` – официальный драйвер MongoDB для Node.js.
●`dotenv` – позволяет загружать переменные окружения из файла `.env`.
1.Настройка ES6 модулей
В файле `package.json`, который был создан на предыдущем шаге, добавьте `"type": "module"` в корень JSON-объекта. Это нужно для того, чтобы использовать современный синтаксис `import/export` вместо `require`.
3.Создание файла `.env` для конфиденциальных данных
○Создайте файл `.env` в корне проекта, этот файл будет содержать переменные окружения, такие как строка подключения к базе данных MongoDB.
○Откройте файл `.env` в редакторе и добавьте туда строку подключения к вашей базе данных. Например:
○MONGO_URI=mongodb://localhost:27017/mydatabase
3.Настройка подключения к MongoDB в файле `./db/index.js`
○В корне вашего проекта создайте папку `db`, в которой будет храниться файл для подключения к базе данных:
○В этой папке создайте файл `index.js`, который будет отвечать за подключение к MongoDB. В нём вы будете настраивать клиент MongoDB и функции для работы с базой данных.
○В файле `index.js` необходимо реализовать подключение к базе данных с использованием MongoDB Driver и загрузку строки подключения из файла `.env`. В будущем это позволит вам работать с базой данных из основного приложения.
5.Настройка основного файла приложения `./app.js`
○Создайте файл `app.js` в корне проекта, он станет основной точкой входа в ваше приложение. Здесь вы настроите сервер Express и подключение к базе данных.
○В файле `app.js` необходимо подключить пакет `dotenv`, чтобы загружать переменные окружения из файла `.env`.
○Импортируйте функции, которые вы создали в файле `db/index.js`, чтобы подключаться к базе данных MongoDB при запуске сервера.
○В файле `app.js` вы должны настроить Express сервер и обеспечить его запуск только после успешного подключения к MongoDB. Это необходимо для того, чтобы сервер был готов работать с базой данных, когда к нему поступят запросы.
6.Запуск сервера и проверка работы
○Убедитесь, что сервер MongoDB запущен.
○Запустите ваше Node.js приложение.
○Если всё настроено правильно, в терминале должно появиться сообщение о успешном подключении к MongoDB и запуске сервера Express.
6.Проверка работы сервера
○Проверьте работу сервера через браузер или Postman:
○Откройте браузер и введите адрес `http://localhost:3000`, чтобы убедиться, что сервер отвечает на запросы.
