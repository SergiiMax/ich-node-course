1.Подготовка проекта
○Убедитесь, что ваш проект настроен - у вас должен быть настроен проект с Express и подключение к MongoDB через файл `./db/index.js`.
○Откройте основной файл приложения (`./app.js`), в этом файле вы будете добавлять маршруты для работы с коллекцией `users`.
1.Создание маршрута для добавления нового пользователя (POST /users)
Настройте маршрут `POST /users`:
○Создайте обработчик маршрута, который будет принимать данные нового пользователя из тела запроса.
○Проверьте, что все обязательные поля (например, имя и email) присутствуют и валидны.
○Если проверка пройдена, добавьте пользователя в коллекцию `users` с помощью MongoDB Driver.
○Возвращайте данные созданного пользователя в ответе.
