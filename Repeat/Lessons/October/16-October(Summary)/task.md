3.Создание маршрута для получения всех пользователей (GET /users)
Настройте маршрут `GET /users`:
○Создайте обработчик маршрута, который будет извлекать всех пользователей из коллекции `users`.
○Используйте метод `find` MongoDB Driver, чтобы получить список всех пользователей.
○Возвращайте список пользователей в ответе.

Настройте маршрут `GET /users/:id`:
○Создайте обработчик маршрута, который будет принимать ID пользователя из параметров URL.
○Проверьте, что ID является допустимым ObjectId.
○Найдите пользователя по ID с помощью MongoDB Driver и верните его данные в ответе.
○Если пользователь не найден, верните ошибку с кодом `404`.

5.Создание маршрута для обновления пользователя (PUT /users/:id)
Настройте маршрут `PUT /users/:id`:
○Создайте обработчик маршрута, который будет принимать ID пользователя из параметров URL и новые данные из тела запроса.
○Проверьте, что ID является допустимым ObjectId и что новые данные валидны.
○Обновите данные пользователя в коллекции `users` с помощью MongoDB Driver.
○Если обновление прошло успешно, верните сообщение о том, что данные пользователя обновлены.
