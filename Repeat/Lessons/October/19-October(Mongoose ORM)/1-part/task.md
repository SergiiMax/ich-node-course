1. Установка Mongoose
    ○Запустите терминал или командную строку в корневой папке вашего проекта Express.
    ○В терминале введите следующую команду для установки Mongoose:
    npm install mongoose
    ○Эта команда скачает и установит библиотеку Mongoose в ваш проект, а также добавит её в зависимости (`dependencies`) вашего проекта.
    ○Убедитесь, что установка прошла успешно, проверив, что папка `node_modules` содержит Mongoose, а файл `package.json` обновлен с новой зависимостью.
2. Подключение Mongoose к вашему проекту
    ○Откройте файл, в котором настроен ваш Express сервер.
    ○В верхней части файла, где вы импортируете необходимые модули, добавьте код для подключения Mongoose. Это позволит вашему приложению использовать Mongoose для взаимодействия с MongoDB.
3. Настройка подключения к MongoDB
    ○Определите строку подключения к вашей базе данных MongoDB. Если вы работаете с локальной базой данных, строка подключения будет выглядеть так: `mongodb://localhost:27017/название_вашей_базы`.
    ○Если вы используете удалённую базу данных, например, MongoDB Atlas, строка подключения будет другой, и вы получите ее от провайдера.
4. Управление подключением
    ○Настройте Mongoose для обработки подключения к базе данных.
    ○Убедитесь, что вы добавили обработку успешного подключения и возможных ошибок. Это важно для отладки и понимания, что происходит с подключением.
5.  Тестирование подключения
○Вновь откройте терминал в корне вашего проекта и запустите Express сервер.
○Если подключение к базе данных настроено правильно, вы увидите сообщение о успешном подключении к MongoDB в консоли. Если возникнут ошибки, внимательно прочитайте их и исправьте проблему.

1. Создание файла для схемы и модели
○В корне вашего проекта создайте новую папку, которую необходимо назвать `models`.
    ○В этой папке будут храниться все ваши схемы и модели.
    ○Внутри папки `models` создайте новый файл с именем `User.js`. Этот файл будет содержать схему и модель для пользователя.
2. Определение схемы User
В начале файла `User.js` вам нужно импортировать библиотеку Mongoose. Это позволит вам использовать её для создания схемы и модели.
3. Создайте схему для User
    ○Используйте конструктор `mongoose.Schema`, чтобы определить поля для сущности `User`. Вам нужно создать три поля:
    ●`name`: строковое поле для хранения имени пользователя.
    ●`email`: строковое поле, которое должно быть уникальным и обязательным.
    ●password`: строковое поле, которое должно быть обязательным.
4. Настройте валидацию
    ○Убедитесь, что поля `email` и `password` обязательны для заполнения. Это можно сделать, добавив валидацию в схему.
    ○Поле `email` должно быть уникальным, чтобы два пользователя не могли зарегистрироваться с одинаковыми адресами электронной почты. Это нужно настроить в опциях поля.
5. Создание модели на основе схемы
    ○На основе созданной схемы создайте модель, используя метод `mongoose.model()`.
    ○Модель будет называться `User`, и она будет представлять коллекцию `users` в базе данных.
    ○В конце файла не забудьте экспортировать созданную модель, чтобы её можно было использовать в других частях вашего приложения.
6. Подключение модели в вашем приложении
В основном файле приложения импортируйте модель `User`, чтобы использовать её для создания, чтения, обновления или удаления данных пользователей.
