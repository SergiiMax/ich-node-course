1. Установка и настройка Express
Создайте новую папку для проекта, например, `network-debugging-lesson`.
2. Инициализируйте новый Node.js проект
В терминале выполните команду `npm init -y`, чтобы создать файл `package.json`.
3. Установите Express
В терминале выполните команду `npm install express`, чтобы установить Express, который будет использоваться для создания сервера.
4. Создание простого Express-сервера
    ○В папке проекта создайте новый файл `app.js`. Это будет основной файл вашего сервера.
    ○Откройте `app.js` в любом текстовом редакторе или IDE. Настройте сервер так, чтобы он прослушивал HTTP-запросы и возвращал простые ответы на них.
    ○Настройте сервер так, чтобы он обрабатывал GET-запрос по пути `/` и возвращал простой текстовый ответ, например, "Hello, World!".
    ○Настройте сервер так, чтобы он обрабатывал POST-запрос по пути `/data` и возвращал текстовый ответ, подтверждающий получение данных, например, "Data received".
5. Запуск сервера
    ○В терминале выполните команду `node app.js`, чтобы запустить сервер. Убедитесь, что сервер запущен и готов принимать запросы.
    ○В браузере введите `http://localhost:3000/`, чтобы отправить GET-запрос. Вы должны увидеть ответ от сервера, который вы настроили.
6. Анализ запросов
    ○Откройте панель инструментов разработчика (F12).
    ○Переключитесь на вкладку Network. Здесь вы увидите список всех сетевых запросов, которые были отправлены вашим браузером.
7. Проанализируйте GET-запрос
    ○Найдите в списке запросов тот, который был отправлен на `http://localhost:3000/`.
    ○Кликните на него, чтобы увидеть детали: заголовки, тело запроса (если есть) и ответ от сервера.
8. Отправьте POST-запрос с помощью Postman или браузера
    ○При помощи Postman отправьте POST-запрос на `http://localhost:3000/data` с любыми данными.
    ○В Network вкладке найдите отправленный POST-запрос. Проанализируйте его заголовки и тело, а также посмотрите, как сервер обработал этот запрос.
