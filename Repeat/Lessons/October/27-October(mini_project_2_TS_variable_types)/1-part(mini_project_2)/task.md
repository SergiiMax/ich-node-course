1. Инициализируйте проект:
    ○Откройте терминал в нужной папке и введите `npm init` и следуйте инструкциям.
  
2. Установите необходимые пакеты:
Введите `npm install express mongoose dotenv`.
3. Создайте базовую структуру проекта:
Создайте файлы и папки: `app.js`, `routes/`, `models/`, `db/`.
4. Настройте `app.js` для работы с JSON данными:
    ○Подключите Express и настройте `express.json()` для обработки JSON данных.
    ○Настройте сервер, чтобы он запускался на порту 5000 или на том, который будет указан в переменной окружения.

1.Создайте файл конфигурации `db/index.js`:
    ○В папке `db/` создайте файл `index.js`.
    ○Напишите функцию для подключения к MongoDB с использованием Mongoose.
2.Настройте файл `.env`:
В корне проекта создайте файл `.env` и добавьте в него строку подключения к базе данных `MONGO_URI`.
3.Настройте `app.js` для подключения к базе данных:
    ○Импортируйте `dotenv` и вызовите `dotenv.config()` для загрузки переменных окружения.
    ○Импортируйте и вызовите функцию `connectDB()` для установки соединения с базой данных.
4.Убедитесь, что подключение успешно установлено:
    ○Запустите сервер (например, с помощью команды `node app.js`).
Проверьте, что в консоли появляется сообщение об успешном подключении к MongoDB.
