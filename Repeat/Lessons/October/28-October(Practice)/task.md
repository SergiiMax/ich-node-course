Создание типизированного объекта
1. Создайте объект `car`, который будет описывать машину.
2. Объект должен содержать следующие свойства:
    ○`brand` (строка)
    ○`model` (строка)
    ○`year` (число)
    ○`isElectric` (булево значение)
3. Затем напишите функцию `describeCar`, которая принимает этот объект в качестве параметра и возвращает строку с описанием машины в следующем формате: "Brand Model (Year), Electric: Yes/No".

Типизация массива с числами
1.Создайте массив чисел `scores`, представляющий результаты тестов студентов.
1.Напишите функцию `averageScore`, которая принимает этот массив и возвращает средний балл.


Использование кортежей
1.Создайте кортеж `personInfo`, который содержит имя (строка) и возраст (число).
1.Затем напишите функцию `printPersonInfo`, которая принимает этот кортеж как параметр и выводит его элементы в консоль в виде объекта.

Создайте кортеж personInfo, который содержит имя (строка) и возраст (число).
Опишите тип Person для объекта со свойствами name (строка) и age (число).
Затем напишите функцию getPerson, которая принимает этот кортеж как параметр и возвращает объект типа Person, где первый элемент кортежа становится свойством name, а второй – свойством age.
Выведите полученный объект в консоль.


Обработка неизвестного типа
1.Создайте переменную `data` типа `unknown`, которая может принимать значения разных типов.
1.Напишите функцию `processData`, которая принимает эту переменную и проверяет ее тип.
1.Если это строка, функция должна вернуть её длину.
1.Если это число, функция должна вернуть его квадрат. В любом другом случае функция должна вернуть `null`.
