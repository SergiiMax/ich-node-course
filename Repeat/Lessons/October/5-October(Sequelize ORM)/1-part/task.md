1.Создание проекта Node.js
○Откройте терминал или командную строку.
○Перейдите в папку, где вы хотите создать проект.
○Запустите команду `npm init -y`, чтобы создать новый проект Node.js. Это создаст файл `package.json`.
2.Установка зависимостей
В том же терминале выполните команду `npm install express sequelize sequelize-cli mysql2`. Эта команда установит все необходимые пакеты:
○Express для создания сервера.
○Sequelize для работы с базой данных.
○Sequelize CLI для автоматизации задач.
○MySQL2 для подключения к базе данных MySQL.
3.Инициализация Sequelize
После установки зависимостей выполните команду `npx sequelize-cli init`. Эта команда создаст несколько папок:
○`config`: Здесь будет файл настроек подключения к базе данных.
○`models`: Здесь будут храниться модели данных.
○`migrations`: Здесь будут храниться миграции для управления структурой базы данных.
○`seeders`: Эта папка для начального заполнения базы данных.
4.Настройка Express
Создайте файл `app.js` в корне вашего проекта. Внутри `app.js`:
○Подключите Express.
○Создайте простой сервер, который будет отвечать на запросы.
○Убедитесь, что сервер запускается и работает корректно.

1.Создание файла `db.js`
В директории config вашего проекта создайте новый файл с именем `db.js`.
1.Настройка `db.js`
○В этом файле настройте подключение к базе данных MySQL с использованием Sequelize.
○Убедитесь, что вы импортируете необходимые модули и загружаете конфигурацию из файла `config.json`.
○Настройте экземпляр Sequelize, используя параметры из конфигурационного файла, и экспортируйте его для использования в других частях вашего приложения.
3.Обновление файла `app.js`
○Откройте файл `app.js` вашего Express-приложения.
○Подключите созданный вами файл `db.js` в начале файла `app.js`. Это нужно для того, чтобы иметь возможность использовать подключение к базе данных через Sequelize.
○Внесите изменения в код, чтобы приложение могло проверять подключение к базе данных при запуске сервера. Это обеспечит корректную работу приложения и позволит быстро узнать о возможных проблемах с базой данных.
4.Проверка работы
○После внесения изменений запустите ваше Express-приложение.
○Убедитесь, что сервер успешно запускается и подключается к базе данных MySQL. Если все настроено правильно, в консоли должно появиться сообщение о успешном подключении к базе данных.

1.Создание папки для моделей (если она отсутствует):
В корневом каталоге вашего проекта найдите или создайте папку под названием `models`. В этой папке будут храниться все модели, которые вы создадите для работы с базой данных.
2.Создание файла для модели `User`:
Внутри папки `models` создайте новый файл с именем `user.js`. Этот файл будет содержать описание модели `User`, которая будет представлять пользователей в базе данных.
3.Импорт необходимых модулей:
В начале файла `user.js` импортируйте модули `DataTypes` из пакета `sequelize` и ваш ранее созданный экземпляр `sequelize` из файла `db.js`. Эти модули понадобятся вам для определения структуры модели и её подключения к базе данных
4.Определение модели `User`:
○В файле `user.js` создайте модель `User`, используя метод `sequelize.define`. Эта модель будет соответствовать таблице `Users` в базе данных.
○Определите поля (столбцы) модели, такие как `name` (имя пользователя), `email` (электронная почта) и `createdAt` (дата создания записи). Укажите типы данных для каждого поля, отметьте, какие из них обязательны, и какие имеют уникальные значения.
○Обратите внимание на то, как модель связана с таблицей в базе данных. Явно укажите имя таблицы и настройте другие параметры, такие как отключение автоматического добавления временных меток.
5.Экспорт модели:
В конце файла `user.js` экспортируйте модель `User`, чтобы вы могли использовать её в других частях вашего приложения, например, для выполнения операций с пользователями в базе данных.

Миграции
# создать миграцию
npx sequelize-cli migration:generate --name create-user-table

# применить миграцию
npx sequelize-cli db:migrate

# откатить миграцию
npx sequelize-cli db:migrate:undo

# Откатить все миграции 
npx sequelize-cli db:migrate:undo:all
