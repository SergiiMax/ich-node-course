1.Создание User
В папке `models` создайте файл `user.js`.
Создайте и настройте модель, определите следующие поля у модели:
○`name`: Имя пользователя (обязательное строковое поле).
○`email`: Почта пользователя (обязательное уникальное строковое поле).
○`createdAt`: Дата создания (хранит дату создания записи).
1.Создание модели `Post`.
В папке `models` создайте файл `post.js`.
Создайте и настройте модель, определите следующие поля у модели:
○`id`: Уникальный идентификатор записи, который автоматически увеличивается с каждой новой записью.
○`title`: Заголовок поста (обязательное строковое поле).
○`content`: Содержимое поста (обязательное текстовое поле).
`userId`: Внешний ключ, связывающий пост с пользователем (обязательное числовое поле)

==============================

1.Настройте файл index.js для управления ассоциациями между моделями.
`User.hasMany(Post)`: Эта строка определяет связь "один пользователь имеет много постов". Внешний ключ `userId` хранится в таблице `Posts` и связывается с `User`.
`Post.belongsTo(User)`: Эта строка указывает, что каждый пост принадлежит одному пользователю. Поле `userId` в таблице `Posts` используется для ссылки на `User`.
1.Проверьте результат.
При помощи MySQL Workbench убедитесь, что таблицы создались и все работает так, как должно.
