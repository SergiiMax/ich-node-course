Создание простого HTTP сервера с маршрутизацией
1.Откройте ваш редактор кода и создайте новую директорию для проекта, например, `routerWebServer`.
1.Внутри директории проекта создайте файл с именем `server.js`.
1.В начале файла `server.js` импортируйте встроенный модуль `http`.
1.Используйте метод `http.createServer`, чтобы создать сервер. Определите функцию обратного вызова, которая принимает объекты `request` и `response`.
1.Реализуйте маршруты в функции обратного вызова:
○`/` - главная страница, отвечает текстом "Welcome to the Home Page!".
○`/about` - страница "О нас", отвечает текстом "About Us".
○Любой другой маршрут - отвечает текстом "404 Not Found".
Используйте метод `listen` объекта сервера, чтобы запустить его на определенном порту (например, 3000).
           Выведите сообщение в консоль, чтобы убедиться, что сервер запущен.
7.        В терминале перейдите в директорию проекта и выполните команду `node server.js` для запуска сервера.
8.        Откройте браузер и перейдите по адресу `http://localhost:3000`, `http://localhost:3000/about`, и любому другому
           адресу, чтобы убедиться, что сервер правильно обрабатывает маршруты.
