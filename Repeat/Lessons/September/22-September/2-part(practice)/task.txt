Регистрация нескольких обработчиков на одно событие
1.Создайте новый файл с именем `multiple_handlers.js`.
1.Импортируйте модуль `events` и создайте экземпляр `EventEmitter`.
1.Зарегистрируйте первый обработчик для события `event`.
1.Зарегистрируйте второй обработчик для того же события `event`.
1.Сгенерируйте событие `event`.
1.Запустите скрипт и убедитесь, что оба обработчика вызываются при генерации события.

task 2

Удаление обработчика события
1.Создайте новый файл с именем `remove_handler.js`.
1.Импортируйте модуль `events` и создайте экземпляр `EventEmitter`.
1.Определите функцию-обработчик, которая будет регистрироваться для события `event`.
1.Зарегистрируйте этот обработчик для события `event`.
1.Сгенерируйте событие `event` и убедитесь, что обработчик вызывается.
1.Удалите зарегистрированный обработчик для события `event`.
1.Снова сгенерируйте событие `event` и убедитесь, что обработчик больше не вызывается.

task 3 =======================================================

Использование метода `once` для одноразовых событий
1.Создайте новый файл с именем `once_handler.js`.
1.Импортируйте модуль `events` и создайте экземпляр `EventEmitter`.
1.Зарегистрируйте обработчик для события `event` с использованием метода `once`.
1.Сгенерируйте событие `event` и убедитесь, что обработчик вызывается.
1.Снова сгенерируйте событие `event` и убедитесь, что обработчик больше не вызывается, так как он был одноразовым.

task 4 ==================================================

Таймер обратного отсчета
1.Создайте новый файл с именем `countdown_timer.js`.
1.Импортируйте модуль `events` и создайте экземпляр `EventEmitter`.
1.Напишите функцию `countdown`, которая принимает количество секунд и объект `EventEmitter`.
1.Внутри функции `countdown` используйте `setInterval`, чтобы каждую секунду генерировать событие `tick` с текущим оставшимся временем.
1.Когда таймер достигнет нуля, генерируйте событие `end` и остановите интервал.
1.Зарегистрируйте обработчики для событий `tick` и `end`, чтобы выводить сообщения в консоль.
1.Вызовите функцию `countdown` с начальным временем и вашим объектом `EventEmitter`.
