<!-- task 1 ============================================================================ -->
Система уведомлений
1.Создайте новый файл с именем `notification_system.js`.
1.Импортируйте модуль `events` и создайте экземпляр `EventEmitter`.
1.Напишите функцию `sendNotification`, которая принимает сообщение и объект `EventEmitter`.
1.Внутри функции `sendNotification` генерируйте событие `notification` с переданным сообщением.
1.Зарегистрируйте несколько обработчиков для события `notification`, например, один для логирования в консоль, другой для записи в файл.
1.Вызовите функцию `sendNotification` несколько раз с разными сообщениями.

<!-- task 2 ================================================================================ -->

Управление состоянием пользователя
1.Создайте новый файл с именем `user_state.js`.
1.Импортируйте модуль `events` и создайте экземпляр `EventEmitter`.
1.Напишите функцию `changeUserState`, которая принимает новый статус и объект `EventEmitter`.
1.Внутри функции `changeUserState` генерируйте событие `stateChange` с переданным статусом.
1.Зарегистрируйте обработчики для события `stateChange`, чтобы выводить новый статус в консоль.
1.Вызовите функцию `changeUserState` несколько раз с разными статусами.
