<!-- task1 =================================================== -->
1.Инициализировать новый проект Node.js с помощью команды `npm init`:
○Перейдите в терминале в папку вашего проекта.
○Запустите команду `npm init` и следуйте инструкциям, чтобы создать файл `package.json`.
1.Установить пакет `lodash` и добавить его в `package.json`:
○Введите команду `npm install lodash`.
1.Создать простой скрипт, использующий одну из функций `lodash`:
○Создайте файл `index.js` и добавьте в него следующий код:
                             const _ = require('lodash');
                             const numbers = [1, 2, 3, 4, 5];
                             const shuffled = _.shuffle(numbers);
                             console.log('Original array:', numbers);
                             console.log('Shuffled array:', shuffled);
○Запустите скрипт командой `node index.js` и убедитесь, что он работает.

<!-- task 3 =========================================================== -->
1.Создайте новый проект:
○В терминале перейдите в каталог, где хотите создать проект.
○Выполните команду `npm init -y`, чтобы инициализировать новый проект с файлом `package.json`.
1.Установите axios:
○Выполните команду `npm install axios`, чтобы установить библиотеку `axios`.
1.Создайте файл для выполнения запроса:
○В корневом каталоге проекта создайте файл `axios-example.js`.
1.Настройте axios для выполнения GET-запроса:
○Откройте файл `axios-example.js` в текстовом редакторе.
○Импортируйте модуль `axios`.
○Настройте GET-запрос к публичному API JSONPlaceholder (`https://jsonplaceholder.typicode.com/todos/1`). Выведите результат запроса в консоль.
5.    Запустите скрипт: в терминале выполните команду `node axios-example.js`, чтобы запустить скрипт и увидеть результат в консоли.

<!-- task 4 =============================================================== -->
1.Создайте новый проект (если его еще нет):
○В терминале перейдите в каталог, где хотите создать проект.
○Выполните команду `npm init -y`, чтобы инициализировать новый проект с файлом `package.json`.
1.Установите dotenv:
○Выполните команду `npm install dotenv`, чтобы установить библиотеку `dotenv`.
1.Создайте файл .env:
○В корневом каталоге проекта создайте файл с именем `.env`.
○Добавьте в файл строку `MY_VAR=HelloWorld`, чтобы задать значение переменной `MY_VAR`.
1.Создайте файл для чтения переменной окружения:
В корневом каталоге проекта создайте файл `dotenv-example.js`.
Настройте dotenv для чтения переменной окружения:
○Откройте файл `dotenv-example.js` в текстовом редакторе.
○Импортируйте модуль `dotenv` и вызовите метод `config` для загрузки переменных окружения из файла `.env`.
○Выведите значение переменной `MY_VAR` в консоль.
6.   Запустите скрипт:
○В терминале выполните команду `node dotenv-example.js`, чтобы запустить скрипт и увидеть значение переменной `MY_VAR` в консоли.
